# 🎢 Dark Ride Atlas | 全球主题乐园黑暗乘骑与暗黑剧场硬件机制百科全书

**Dark Ride Atlas** 是一套面向主题乐园工程爱好者、游乐设备研究者与乐园玩家的交互式全景百科网站。

## ✨ 核心功能板块（六大模块）

1. **🌐 全球标杆项目与视频探秘库 (Global Ride & Video Explorer)**
   - 收录全球各大机制标杆项目，支持按 **6 大乐园体系**、**5 大行进式门类 + T1~T6 剧场门类**、**核心硬件制造商**（`Oceaneering`、`KUKA`、`ETF`、`Mack Rides`、`Intamin`、`Simtec`、`Dynamic Attractions`、`Vekoma`、`Brogent`、`华强方特`、`WDI`）多维交叉筛选。
   - **🎬 站内高清视频弹窗播放器 (In-App Cinema Modal)**：支持直接在网页内一键切换播放 **4K 全程 POV**、**💡 清场开灯揭秘 (Lights-On)** 与 **🔧 硬件制造商工厂裸车测试 (Factory Demo)**，并提供 Bilibili 实拍直达。
   - **⚖️ 硬件参数横向 PK 工具**：任选 2~3 个项目（如《蜘蛛侠》vs《印第安纳琼斯》vs《秦俑地宫》）同屏对比轨道导引、自由度（DOF）、视觉载体与制造商。
2. **🌳 硬件机制全景树 (Variable-Depth Mechanism Logic Tree)**
   - **第一部分（狭义行进式 Dark Ride）**：按物理支撑与导引介质科学划分为 **5 大顶层门类**（地面水平有轨、地面无轨 AGV、空中顶部悬挂、垂直井道升降、涉水船与真水下潜艇），采用 **2~4 级可变深度逻辑树**（共 29 个底层机制亚种）。
   - **第二部分（广义暗黑剧场与动感平台）**：涵盖 `T1` 球幕飞行影院（四大入场机械流派）、`T2` 动感模拟舱/全封闭 360° LED 球体/原地机械臂、`T3` 行走看台车与多级行星倾斜旋转舞台、`T4` 360° 环幕隧道大巴、`T5` 疯屋视错觉滚筒、`T6` 佩珀尔全息幻象与千块空间魔砖矩阵。
3. **🔬 交互式机械透视实验室 (Interactive SVG X-Ray & 6-DOF Lab)**
   - 内置 **6 组可拖动自由度滑块（Pitch / Roll / Yaw / 升降行程）的 SVG 工程透视蓝图**：
     1. `1.1.3.1` 地面导轨 KUKA 6 轴工业机械臂（《禁忌之旅》）vs `3.3` 天花板悬挂 240° 抓举动感座舱（方特《烈焰风云》）
     2. `1.1.2.1` 车载 6-DOF + 360° 自转 SCOOP 动感车（《蜘蛛侠/变形金刚/女娲补天》）vs `1.1.2.3` 12 座 EMV 液压越野吉普（《印第安纳琼斯/秦俑地宫》）
     3. `2.2.2` 方特《神画 / 千古风华》无轨多自由度车 + 内凹倾斜球幕悬崖停靠（《千里江山图》飞跃揭秘）
     4. `5.1.3.1` 上海迪士尼《加勒比海盗》水下直线电机全向自转船 vs `5.1.3.2` 法国 Futuroscope《Mission Bermudes》Mack 水下万向球铰摇摆快艇
     5. `T3.1` 荷兰 Efteling《Danse Macabre》18 米倾斜升降主转盘 vs `T2.5` 阿布扎比《Hypersphere 360°》全封闭 LED 球体内部悬挂环
     6. `T1.1 ~ T1.4` 悬挂式球幕飞行影院四大入场机械流派动态模拟器（顶置钢缆提拉 vs 多层水平前推 vs 巨型钢架拉升 vs 平地入座 90° 整体翻转竖立）
4. **🏰 全球六大乐园体系全项目盘点矩阵 (69 座主题乐园穷举)**
   - `3.1` 全球迪士尼（6 大度假区 12 座乐园）
   - `3.2` 全球环球影城（7 座主题乐园，含 2025 奥兰多 Epic Universe）
   - `3.3` 中国方特（全国 38 座乐园全系项目按硬件机制精准归类，含一期看台版 vs 二期吉普版《秦陵历险》区分）
   - `3.4` 迪拜与阿布扎比（7 大标杆乐园）
   - `3.5` 马来西亚吉隆坡云顶天城世界（Genting SkyWorlds 全项目）
   - `3.6` 欧洲四大暗黑标杆乐园（德国 Phantasialand、荷兰 Efteling、德国 Europa-Park、法国 Futuroscope）
5. **⚖️ 六大核心工程辨析深度专篇**
6. **👁️ 视觉演艺（7大技术）与玩家交互机制（8大技术）速查矩阵**

## 🚀 本地运行与预览

本项目采用零构建依赖（Zero-Build）原生模块化架构，可直接双击 `index.html` 打开，或使用 Python 启动本地 HTTP 服务：

```bash
python3 -m http.server 8080
# 随后在浏览器访问 http://localhost:8080
```
